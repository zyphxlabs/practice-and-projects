### Lab Practice Writing Python Code


## What This Lab Covered
This lab was my first real hands on time inside a notebook environment and it was mostly about getting comfortable with the two types of cells you work with which are markdown cells and code cells. Markdown cells are just plain text that you can format while code cells are where the actual Python goes and gets executed. I ran through a series of tasks that had me writing comments and using the print() function to display different strings to the screen.

## What I Actually Did
I started by editing a markdown cell just to get a feel for how the formatting works before moving into the code cells. After that I ran a pre written cell containing the comment This cell displays "Hello world!" followed by print("Hello world!") and observed the output was just Hello world! showing up on the screen exactly as expected.

Next I ran a cell that had nothing but comments in it starting with the hash symbol and there was no output at all which made sense once I thought about it because Python skips over comments entirely when it executes code. Comments are not for the computer they are notes left behind for me and anyone else reading the code later.

After that I wrote my own comment above a print statement describing what the code does then ran print("I am using Python.") and the output came back as I am using Python. without the quotation marks showing which was something I noticed carries through every single print statement in this lab.

I kept going and wrote print("I am a security analyst.") on my own this time not just filling in a blank and it printed exactly as written. Same thing again with print("Python is useful for security!") which also ran clean on the first try.

For the last task I combined every single print statement from the whole lab into one code cell so it read

- print("Hello world!")
- print("I am using Python.")
- print("I am a security analyst.")
- print("Python is useful for security!")

and when I ran it the output displayed each line in the exact order they appeared in the code starting with Hello world! then I am using Python. then I am a security analyst. and finishing with Python is useful for security! That confirmed for me that Python reads and executes code top to bottom and left to right which is something I want to keep in mind going forward since order is going to matter a lot more once the scripts get more complex.

## Key Takeaways
- Code comments are for people not computers and Python ignores anything after a hash symbol
- print() is how you get information to display to the screen
- Quotation marks around a string never show up in the actual output
- Python executes everything in order from top to bottom which will matter a lot once I start writing longer scripts
